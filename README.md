# Honey Badger Launchpad

Honey Badger Outfits — Premium Ecommerce Website Build



You are acting as a senior product designer, luxury fashion ecommerce UX designer, conversion-rate optimization specialist, brand strategist, and senior frontend engineer.



Your job is to design and build a premium ecommerce website for my clothing brand:



BRAND: Honey Badger Outfits

CATEGORY: Men's sportswear / athleisure

HERO PRODUCT: Premium 4-Way Stretch Lycra Track Pants



The website must look like a serious independent fashion/sportswear brand, not like a generic AI-generated ecommerce template.



1. Primary objective



Build a website that:



- Looks premium and trustworthy

- Makes the product visually desirable

- Works exceptionally well on mobile

- Converts visitors into WhatsApp enquiries/orders

- Loads quickly

- Is SEO-friendly

- Is easy for me to maintain

- Can be deployed for free

- Does not require a backend for the initial version



Do not over-engineer the project.



The first version should prioritize:

brand perception + product presentation + conversion.



---



2. Technology



Use:



- React

- Vite

- TypeScript if appropriate

- Tailwind CSS

- Modern semantic HTML

- Responsive CSS

- Lucide icons or another lightweight icon library

- Motion/Framer Motion only where it genuinely improves UX



Do NOT introduce unnecessary dependencies.



Keep the architecture clean and understandable.



The site should be deployable on Vercel using a free account.



---



3. Brand direction



Honey Badger Outfits should feel:



- Bold

- Masculine

- Athletic

- Premium

- Modern

- Confident

- Minimal

- Functional



Avoid:



- Cheap-looking ecommerce design

- Excessive gradients

- Excessive glassmorphism

- Cartoon graphics

- Generic stock-fashion layouts

- Too many colours

- Excessive animations

- Fake luxury language

- Fake reviews

- Fake statistics

- Fake customer claims



The design should have strong visual hierarchy and generous whitespace.



Use a restrained palette based around:



- Black

- Off-white

- Charcoal

- Neutral grey

- One controlled brand accent colour



Do not randomly introduce additional colours.



---



4. Typography



Use a modern premium sans-serif typeface.



Create a clear hierarchy:



- Large editorial-style hero typography

- Strong section headings

- Clean product titles

- Highly readable body text

- Compact supporting text



Typography should feel closer to a modern sportswear/fashion brand than a marketplace.



Do not use excessive font weights or decorative fonts.



---



5. Website structure



Create the following pages/sections:



HOME



Header



Desktop:



HONEY BADGER logo



Navigation:



- Home

- Track Pants

- About

- Size Guide

- Contact



Right side:



- Search

- Cart if implemented

- WhatsApp/order CTA



Mobile:



- Logo

- Menu

- WhatsApp/order CTA



Header should become compact/sticky when scrolling.



---



HERO



Create a high-impact full-width hero.



Main headline:



MOVE DIFFERENT.



Supporting headline:



Premium stretch track pants built for movement, comfort and everyday wear.



Primary CTA:



SHOP TRACK PANTS



Secondary CTA:



ORDER ON WHATSAPP



Use a large premium product/lifestyle image.



The hero must immediately communicate:



1. What the product is

2. Why it is different

3. What the visitor should do next



Do not overcrowd the hero.



---



6. Product benefits



Create a clean four-feature section.



Example:



4-WAY STRETCH

Moves naturally with you.



LIGHTWEIGHT

Comfort without unnecessary weight.



FLEXIBLE FIT

Designed for movement.



EVERYDAY WEAR

Gym, travel or everyday use.



Only use claims that are supported by the actual product information.



---



7. Featured product section



Create a premium product showcase:



THE HB 4-WAY STRETCH TRACK PANT



Include:



- Large product image

- Front image

- Back image

- Detail image

- Fabric/stretch image if available

- Product name

- Short description

- Price placeholder

- Available sizes

- Available colours

- Product features

- WhatsApp order button



Use placeholder product data initially.



Make the product data easy to replace later.



---



8. Product gallery



Create an editorial-style product gallery.



Do NOT make every product card identical if it harms the visual design.



Use varied image proportions while maintaining a coherent grid.



The gallery should feel like a fashion brand campaign rather than a basic marketplace catalogue.



---



9. Product detail experience



When the visitor selects a product, show:



- Product gallery

- Product name

- Price

- Available colours

- Size selection

- Product features

- Fabric information

- Fit information

- Care instructions

- Delivery information

- WhatsApp ordering



CTA:



ORDER ON WHATSAPP



When clicked, generate a WhatsApp message containing:



- Product name

- Selected colour

- Selected size

- Quantity



Use a configurable WhatsApp phone number variable rather than hardcoding the number throughout the application.



---



10. Brand section



Create an "About Honey Badger" section.



Brand positioning:



Honey Badger Outfits is a men's clothing brand focused on comfortable, functional and modern everyday wear.



Keep the copy concise.



Do not invent a fake company history.



Do not claim years of experience, customer numbers, sales numbers or manufacturing capabilities unless I provide them.



---



11. Product demonstration section



Create a strong visual section for product videos.



Headline:



BUILT TO MOVE.



Supporting copy:



Show the stretch, fit and movement of the product.



Provide a video placeholder that I can replace later with my actual product video.



The section should work beautifully with both video and static fallback imagery.



---



12. Size guide



Create a clean size guide.



Use placeholder values initially.



Clearly structure:



Size | Waist | Length | Recommended fit



Make it easy to replace the values later.



On mobile, the size guide must remain readable.



---



13. FAQ



Create useful ecommerce FAQs:



- What fabric is used?

- Does the track pant have stretch?

- What sizes are available?

- How do I choose my size?

- How do I place an order?

- Do you offer returns/exchanges?

- How long does delivery take?



Do not invent policies.



Use clearly marked placeholders where information has not yet been provided.



---



14. Footer



Include:



Honey Badger Outfits



Navigation



Contact



Instagram



WhatsApp



Privacy Policy



Terms



Shipping / Returns



Copyright



Use placeholders for links that I haven't provided yet.



---



15. Mobile-first requirements



Mobile is extremely important.



The website must be designed for users coming from Instagram ads.



Test specifically for:



- 360px width

- 390px width

- 430px width

- Tablet

- Desktop



Avoid:



- Horizontal overflow

- Tiny text

- Buttons too close together

- Huge unnecessary sections

- Slow-loading hero images



CTA buttons should be easy to tap with one hand.



---



16. Instagram traffic optimization



Assume most visitors will come from Instagram.



Therefore:



- Hero must communicate the product immediately

- Product should be visible above the fold

- CTA must appear quickly

- WhatsApp ordering must require minimal effort

- Product images must dominate the page

- Mobile navigation must be simple

- Page load must be fast



Create a sticky mobile CTA if it improves conversion:



ORDER ON WHATSAPP



Do not make it annoying.



---



17. Animations



Use subtle premium animations.



Examples:



- Hero image reveal

- Fade/slide section entrances

- Product image hover

- Button hover

- Smooth image transitions

- Scroll-based reveals



Animations must be:



- Fast

- Subtle

- Purposeful



Do NOT make the site look like an animation demo.



Respect "prefers-reduced-motion".



---



18. SEO



Implement:



- SEO-friendly page titles

- Meta descriptions

- Open Graph metadata

- Twitter/X metadata where appropriate

- Semantic HTML

- Proper H1/H2/H3 hierarchy

- Alt text

- Canonical URL placeholder

- robots.txt

- sitemap.xml

- Product structured data where appropriate



Target relevant search intent around:



- men's track pants

- 4 way stretch track pants

- lycra track pants

- men's sportswear

- men's activewear

- comfortable track pants

- Honey Badger Outfits



Do not keyword stuff.



---



19. Performance



Optimize for:



- Lighthouse performance

- Core Web Vitals

- Mobile loading

- Image lazy loading

- Responsive image sizes

- Minimal JavaScript

- Minimal dependencies



Do not load unnecessary libraries.



Use modern image formats where possible.



---



20. Accessibility



Follow good WCAG practices.



Include:



- Proper semantic elements

- Keyboard navigation

- Visible focus states

- Sufficient contrast

- Alt text

- Accessible buttons

- Accessible navigation

- Reduced-motion support



---



21. Product image system



Do not permanently embed image URLs throughout the code.



Create a central product data structure.



For example:



products.ts



Each product should contain:



- id

- name

- description

- price

- images

- colours

- sizes

- features

- fabric

- fit

- available



I should be able to add another track pant by editing one product object rather than rebuilding the UI.



Use obvious placeholder image paths such as:



/images/products/track-pant-black-front.webp



Make it easy for me to replace them with my actual images.



---



22. WhatsApp ordering



Create one central configuration:



WHATSAPP_NUMBER



Create a reusable function that generates the WhatsApp URL.



Example message structure:



Hi Honey Badger Outfits,



I would like to order:



Product: [PRODUCT]

Colour: [COLOUR]

Size: [SIZE]

Quantity: [QUANTITY]



Please share the order details.



Do not expose API keys or sensitive credentials.



---

Suggested structure:

pages/

data/

assets/

lib/

styles/



Create reusable components such as:



- Header

- Hero

- ProductCard

- ProductGallery

- ProductDetails

- FeatureGrid

- BrandSection

- VideoSection

- SizeGuide

- FAQ

- Footer

- WhatsAppButton



Keep business/product data separate from UI components.



---



24. Important design rule



Do not simply generate a standard Tailwind ecommerce template.



Before writing the UI, think through:



- Visual hierarchy

- Brand identity

- Conversion path

- Mobile experience

- Product photography

- Typography

- Spacing

- CTA placement

- Information density



The finished result should look like a website designed by an experienced ecommerce design team.



---



25. Development process



Work in this order:



Phase 1



Create the design system and layout.



Phase 2



Build the homepage.



Phase 3



Build the product listing.



Phase 4



Build the product detail page.



Phase 5



Add WhatsApp ordering.



Phase 6



Add responsive behaviour.



Phase 7



Add animations.



Phase 8



Implement SEO and performance optimizations.



Phase 9



Run a visual and UX audit.



Phase 10



Fix all issues.



Do not stop after generating the first version.



---



26. Before coding



First provide me with:



1. Proposed sitemap

2. Design direction

3. Colour palette

4. Typography choices

5. Component architecture

6. Recommended folder structure

7. Conversion strategy

8. Any information you need from me



Then proceed with implementation.



If information is missing, use clearly labelled placeholders rather than inventing facts.



---



27. Final quality standard



Before considering the project finished, review it as:



- Senior UI/UX designer

- Fashion ecommerce designer

- Mobile conversion specialist

- SEO specialist

- Frontend engineer

- Accessibility reviewer



Fix issues you identify.



The final website should feel like a real premium sportswear brand and should be suitable for traffic coming from Instagram advertisements.



Do not tell me that something is "good enough."



Aim for production quality while keeping the technology and infrastructure free.
